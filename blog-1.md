# How do the four pillars of OOP help manage logic and reduce complexity in large-scale TypeScript projects?

In TypeScript, these pillars are tools for keeping types predictable and clean

### 1. Inheritance

It prevents us from writing the same code over and over. In large-scale TypeScript projects we can share core logic.

### 2. Polymorphism

It allows different classes to be treated as instances of the same interface, but each implements it's own logic. In other word, it makes our system flexible.

### 3. Abstraction

It allows us to swap out complex logic. It simplifies our view.

### 4. Encapsulation

Encapsulation is about grouping data and methods into a single unit and restricting access to the inner workings. TypeScript’s private, protected, and readonly modifiers allow us to enforce these boundaries at compile-time. In other word, it protects our data.
